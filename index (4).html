Why NOVA

Zero Data Retention

Architecture · Security · Vision

The NOVA ecosystem

♦
Security layers L1–L4
▼
L1 — PII scrubbing
NHI, IRD, phone, email, address stripped before the AI sees any message.
L2 — Session rate limiting
Circuit breaker (opossum) cuts AI at 10s timeout. Prebuilt crisis message returned.
L3 — Zero data retention
Message text NEVER reaches SQLite. Only region, topic, language, hour, crisis flag.
L4 — Helmet CSP + HSTS
Strict CSP, HSTS, SSH tunnel only. Cookie: HttpOnly, SameSite=lax, 8h TTL.
☁
Catalyst Cloud NZ
▼
Data sovereignty
100% NZ infrastructure. HIPC 2020 + Te Mana Raraunga require data stays in Aotearoa.
Infrastructure
c1.c4r8: 4 vCPU / 8GB RAM · Intel Xeon · NVMe · 10Gbps · ~$198 NZD/month.
Why not AWS / GCP / Azure
Overseas servers create HIPC + Māori Data Sovereignty conflicts. Catalyst guarantees NZ residency.
∿
AI engine: phi3 → Mistral
▼
phi3:mini — current
2.3 GB · 4096 token context · CPU-only · 8–15s response. Ideal for demo.
Mistral 7B — phase 2
Apache 2.0 license · self-hosted · 8192 context · 3–5s on c1.c8r16.
Dual AI architecture
Mistral for conversation (empathy) + phi3 for analytics dashboard (speed). Two AIs, two roles.
